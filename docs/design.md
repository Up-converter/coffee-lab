# 咖啡实验台（CoffeeLab）设计文档

## 1. 项目概述

一个个人使用的咖啡冲煮记录 PWA，服务于两类日常场景：

- **意式浓缩**：半自动咖啡机萃取，记录/对比/迭代参数（dial-in）
- **手冲**：滤杯冲煮，记录分段注水等参数与风味

核心理念延续参考图 PourLab（`aebd64b6c39132f761e96cc990b67626.jpg`）：**改变一个变量，发现属于你的风味答案**。支持记录的收藏、并排对比、复制为配方、JSON/CSV 导出。

## 2. 已确认的关键决策

| 决策点 | 结论 |
|---|---|
| 平台 | PWA（手机浏览器打开即用，可添加到主屏幕；桌面浏览器同样可用） |
| 技术方案 | 无构建 vanilla JS + localStorage，零依赖、零网络请求 |
| 功能范围 | 豆子库（也支持直接输入）、配方复用、并排对比、应用内收藏；**不做**内置计时器 |
| 感官体系 | 多维滑块（0-10）+ 星级（1-5）+ 风味标签 + 文字笔记 |
| 导出 | JSON 备份/恢复 + CSV 表格 + 应用内收藏标记；不做分享图片卡片 |
| 器具 | 咖啡机/磨豆机等固定设备在设置页配置一次，自动快照进记录，**不占表单位置**；滤杯留在手冲表单（默认带出上次选择） |
| 视觉 | 延续参考图：深墨绿 `#1E3A2F` + 米白 `#F5F3EC` + 琥珀/棕/绿点缀，衬线大数字，白卡片大圆角 |
| 界面语言 | 中文 |

## 3. 参数字段清单（最终版）

字段分三层：**核心**（表单直接可见）、**进阶**（折叠区"更多参数"，选填）、**自动**（计算/快照，不输入）。
设计原则：日常高频字段直接可见，30 秒能记完一杯；进阶字段折叠不碍事。

### 3.1 豆子库（Bean）

| 字段 | 层级 | 形式 |
|---|---|---|
| 名称 | 核心·必填 | 文本 |
| 烘焙商 | 核心 | 文本，记住常用 |
| 烘焙度 | 核心 | 单选：极浅/浅/中浅/中/中深/深（+自定义文本） |
| 烘焙日期 | 核心 | 日期（养豆天数的计算依据） |
| 产地国家 / 产区 | 核心 | 文本，如 埃塞俄比亚 / 耶加雪菲 |
| 处理法 | 核心 | 单选+自定义：水洗/日晒/蜜处理/厌氧发酵/其他 |
| 豆种 | 进阶 | 文本，如 Heirloom、Geisha、卡蒂姆 |
| 海拔 | 进阶 | 文本 |
| 官方风味描述 | 进阶 | 文本（烘焙商标注） |
| 已喝完 | 核心 | 开关 |
| 备注 | 进阶 | 文本 |

### 3.2 冲煮记录（Brew）—— 共用字段

| 字段 | 层级 | 说明 |
|---|---|---|
| 日期时间 | 核心·必填 | 默认现在 |
| 冲煮方式 | 核心·必填 | 意式 / 手冲（新建时首选，决定表单分支） |
| 咖啡豆 | 核心·必填 | 从豆子库选 **或直接输入豆名**；直接输入时可顺手填烘焙度/烘焙日期，勾选"同时存入豆子库" |
| 粉量 (g) | 核心 | 数字 |
| 研磨刻度 | 核心 | 文本/数字（不同磨豆机刻度体系不同，不限定格式） |
| 水温 (°C) | 核心 | 数字 |
| 萃取时间 (秒) | 核心 | 意式=出液时间；手冲=总时间 |
| 风味评价 | 核心 | 见 3.5 |
| 下次调整计划 | 核心 | 文本，如"下次调粗 1 格 / 减 0.5g 粉"（dial-in 闭环） |
| 收藏 | 核心 | 星标 |
| 水质描述 | 进阶 | 文本，如"农夫山泉""GH 68/KH 40 配方水" |
| 环境温湿度 | 进阶 | 文本 |
| TDS (%) | 进阶 | 数字；填了自动算 EY% |

### 3.3 意式专属字段

| 字段 | 层级 | 说明 |
|---|---|---|
| 液重 (g) | 核心 | 电子秤称出的萃取液重量 |
| 峰值压力 (bar) | 进阶 | 有压力表可记 |
| 预浸 | 进阶 | 时间(秒) + 方式（渐进/低压预浸） |
| 首滴时间 (秒) | 进阶 | 判断通道/研磨的重要参考 |
| 粉碗规格 | 进阶 | 如 58mm / 18g 无底粉碗 |
| 布粉压粉手法 | 进阶 | 文本，如 WDT+布粉器+恒力压粉锤 |
| 饮品类型 | 进阶 | 浓缩/Ristretto/Lungo/美式/拿铁 |
| 萃取观察 | 进阶 | 自由文本：虎斑油脂、通道效应、喷溅、粉饼状态、克丽玛颜色/厚度 |
| 咖啡机 / 磨豆机 | 自动 | 保存时从设置页快照，详情页展示 |

### 3.4 手冲专属字段

| 字段 | 层级 | 说明 |
|---|---|---|
| 注水总量 (g) | 核心 | 粉水比的分子 |
| 滤杯 | 核心 | 文本+记住常用（V60-02/Kalita 155 等），默认带出上次选择 |
| 闷蒸 | 进阶 | 水量(g) + 时间(秒) |
| 分段注水计划 | 进阶 | 结构化段列表，每段"目标克数 + 时间点"，可增删段，如 `45g@0:30 → 135g@1:15 → 225g@2:10` |
| 实际出品液重 (g) | 进阶 | 与注水总量分开记（粉床吸附约 2 倍粉量的水） |
| 绕圈/搅拌手法 | 进阶 | 文本，如"中心向外绕圈，距滤纸 1cm" |
| 滴滤完成时间 | 进阶 | 最后注水到滴完 |
| 磨豆机 | 自动 | 保存时从设置页快照 |

### 3.5 风味评价（两种方式共用）

- **8 维滑块 0-10**：酸质、甜感、苦感、醇厚度(Body)、平衡感、余韵、风味复杂度、干净度（意式额外加第 9 维"浓缩强度"）
- **总体星级** 1-5
- **风味标签**（多选+自定义）：柑橘/莓果/热带水果/花香/焦糖/巧克力/坚果/红茶/绿茶/发酵感/酒感/香料/谷物…
- **品鉴笔记**：自由文本

### 3.6 自动计算（不落库，渲染时实时算）

| 计算 | 公式 |
|---|---|
| 粉液比（意式） | 液重 ÷ 粉量 → 1:2.0 |
| 粉水比（手冲） | 注水总量 ÷ 粉量 → 1:16 |
| 养豆天数 | 记录日期 − 烘焙日期 |
| 萃取率 EY% | 液重(或出品液重) × TDS% ÷ 粉量（良好区间 18-22%） |

### 3.7 设置页"我的器具"（配置一次，自动快照进每条记录）

咖啡机、意式磨豆机、手冲磨豆机、手冲壶、粉碗规格、常用滤纸。全选填。记录详情页展示快照值，历史记录不因设备更换而失真。

## 4. 页面结构与交互

导航：手机（<768px）底部标签栏；桌面（≥768px）左侧深绿侧边栏。四页：**记录 · 豆子 · 对比 · 设置**。

### 4.1 记录页（首页）
- 筛选 chips：`全部 / 意式 / 手冲 / ⭐收藏` + 搜索框（豆名/笔记/风味标签）
- 记录卡片倒序列表：方式 badge、豆名+烘焙度、日期+养豆天数、核心参数大数字（意式 `18g → 36g · 27s · 1:2.0`；手冲 `15g → 240g · 2:30 · 1:16`）、星级、收藏星标
- 悬浮 **「+」** → 新建：先选 意式/手冲，表单**自动预填上一次同方式参数**（只改变量）
- 点卡片 → 详情页

### 4.2 记录表单（新建/编辑）
分组：① 豆子（选库或直接输入）→ ② 核心参数（按方式，ratio 实时显示）→ ③ 更多参数（折叠，进阶字段+分段注水编辑器）→ ④ 风味（滑块/星级/标签/笔记/下次计划）。编辑态额外提供删除。

### 4.3 详情页
完整参数（衬线大数字+分组）+ 风味条可视化 + 标签 + 笔记 + 下次计划；操作：编辑 / 复制为新实验 / 收藏 / 删除。

### 4.4 豆子页
豆子卡片（在喝/已喝完分组）：名称、烘焙度、养豆天数 badge、产地/处理法、该豆记录数与平均星级；新建/编辑/标记喝完。

### 4.5 对比页
- 勾选 2-3 杯（第一杯为基准）
- 参数对照表：不同值高亮（一眼看出实验改了什么变量）
- 风味对比：滑块维度并排条形图
- 底部：任一杯"用作配方"

### 4.6 设置页
我的器具；数据（导出 JSON / 导入 JSON（合并或覆盖）/ 导出 CSV / 清空全部）；PWA 安装引导；版本信息。

**CSV 导出列**（平铺，一行一条记录）：日期、方式、豆名、烘焙度、养豆天数、粉量、液重/注水总量、时间(秒)、水温、研磨刻度、滤杯(手冲)、ratio、星级、8 项风味滑块、风味标签（`|` 连接）、品鉴笔记、下次计划、收藏。进阶字段（压力/预浸/闷蒸/分段注水/TDS/EY 等）一并列出，空值留空。

## 5. 技术架构

```
coffee/
├── index.html            # 唯一入口，系统字体栈（含中文衬线），无 CDN 资源
├── css/style.css
├── js/
│   ├── core.js           # 纯逻辑：ratio/养豆天数/EY 计算、schema 校验与迁移、CSV 生成
│   │                     # UMD 写法：浏览器挂 window，Node 下 module.exports（供测试 require）
│   ├── store.js          # 单一状态树 + CRUD + 防抖保存
│   └── ui/
│       ├── app.js        # hash 路由（#/brews、#/brew/new、#/brew/:id、#/beans、#/compare、#/settings）+ 渲染入口
│       ├── brews.js      # 列表/表单/详情
│       ├── beans.js
│       ├── compare.js
│       └── settings.js
├── manifest.webmanifest
├── sw.js                 # App Shell 缓存（版本化，发版自动失效）
├── icons/                # 192/512 PNG + SVG
└── test/core.test.mjs    # node --test
```

- 无构建工具、无运行时依赖、无外部网络请求（完全离线可用）
- 渲染：模板字符串 + 事件委托，每页一个 render 函数
- UMD 的 core.js 使纯逻辑可在 Node 中直接跑测试

## 6. 数据模型

localStorage 单 key `coffeeLab.data`：

```json
{
  "version": 1,
  "beans": [{ "id", "name", "roaster", "roastLevel", "roastDate", "country", "region",
              "process", "variety", "elevation", "aromatics", "finished", "note", "createdAt" }],
  "brews": [{ "id", "method", "date",
              "beanId", "beanSnapshot": { "name", "roastLevel", "roastDate" },
              "dose", "yield", "time", "temp", "grind", "dripper",
              "advanced": { "espresso": {...} | "pourOver": {...含 pours[] } , "water", "env", "tds" },
              "sensory": { "sliders": {...}, "stars", "tags": [], "notes", "nextStep" },
              "favorite", "gearSnapshot": { "machine", "grinder", ... }, "createdAt" }],
  "gear": { "machine", "espressoGrinder", "pourOverGrinder", "kettle", "basket", "filterPaper" },
  "settings": {}
}
```

- id 用 `crypto.randomUUID()`
- 计算字段（ratio/养豆天数/EY）不存储，渲染时由 core.js 纯函数计算
- 预留 `migrate(version)` 函数做版本演进
- 每次变更防抖 300ms 写入 localStorage

## 7. 数据流

```
UI 事件 → store action（校验+变更内存 state）→ 防抖写 localStorage → 重渲染受影响视图
```

## 8. 错误处理

| 场景 | 处理 |
|---|---|
| localStorage 写入失败/超配额 | 顶部持久警示条"存储失败，请立即导出备份"；内存态继续可用不丢当前会话 |
| 导入 JSON 非法 | 校验 version 与结构，报具体错误，不做任何写入 |
| 导入-合并模式 | 按 id 去重，本机已存在的 id 跳过；完成后提示"新增 X 条、跳过 Y 条" |
| 导入-覆盖模式 | 覆盖前自动先导出一份数据 JSON 下载，提示条告知 |
| 表单非法值 | 数值框即时校验提示；必填仅"豆名+冲煮方式" |
| 删除单条 | confirm 确认 |
| 清空全部 | 需输入"删除"二次确认 |
| 日期解析失败 | 回退为今天 |

## 9. 测试策略

- **自动化**（`node --test`，针对 core.js）：ratio/养豆天数/EY 计算、CSV 生成（逗号引号转义、中文）、schema 校验、版本迁移、导入合并去重
- **端到端验收清单**：新建意式记录 → 新建手冲记录（含分段注水）→ 收藏 → 搜索筛选 → 对比 → 复制为新实验 → 修改豆子后历史记录快照不变 → 导出 JSON → 清空 → 导入恢复 → CSV 打开验证
- 开发过程中本地 `http.server` + 手机浏览器实测移动端布局

## 10. 部署

- 本地：`python3 -m http.server`，手机局域网访问
- 发布：GitHub Pages（或任意静态托管）后获得完整 PWA 能力（离线、主屏图标）

## 11. 明确不做（YAGNI）

内置计时器、分享图片卡片、账号/云同步、蓝牙秤连接、豆仓库存克数/价格管理、冷冻豆管理、拼配豆多组分、照片附件、SCA 完整杯测表、咖啡因统计。以上均可在未来按需追加（数据模型已预留 version 迁移）。
